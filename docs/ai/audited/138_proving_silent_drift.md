  "__main__":`).

    zeros).
  - Define an external physical perturbation `data_seq` representing a slow
    linear drift added to the sensory slice of the state over time (e.g., 100
    steps).

    passing in `data_seq`.

  1. **True Physical Divergence**: `jnp.linalg.norm(x_current - x_init)`.
  2. **Internal Surprisal (Gradient magnitude)**: The L2 norm of
     `jax.grad(energy_fn)(x_current)`. You must compute this using the
     `energy_fn` closure to track the exact restorative force generated by the

       Healthy system vs. the Blind system. (The healthy system should resist
       the drift and stay low; the blind system should drift infinitely).
    2. **Internal Surprisal over time**: Plot the surprisal (gradient magnitude)

       a surprisal of exactly 0.0, proving it doesn't know it's drifting.
  - Print a clear terminal readout diagnosing the results.
